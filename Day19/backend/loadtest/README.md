# RebelMart Batch 7 Load Testing

## Goal
Simulate 50 concurrent users and identify latency, throughput, and failure bottlenecks.

## Setup
From `backend/`:

```bash
pip install -r requirements.txt
```

For meaningful authenticated traffic, export an access token generated by the application:

```bash
export LOCUST_ACCESS_TOKEN="<valid-access-token>"
```

## 50-user test

```bash
locust -f loadtest/locustfile.py --headless -u 50 -r 10 -t 2m --host http://127.0.0.1:8000
```

The test records request count, failures, median latency, average latency, p95/p99 latency, and requests/second.

## Interpretation
- Failure rate should remain near 0%.
- Review p95 first for user-facing API responsiveness.
- Compare `/products`, `/products/count`, `/cart`, and `/orders` to identify database/cache bottlenecks.
- If Redis/PostgreSQL saturates, reduce spawn rate or inspect slow SQL before increasing capacity.
